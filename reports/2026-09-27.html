Emerging Trends

The WordPress 7.2 roadmap is a primary focus for the community, with several key changes confirmed:

  • New Default Theme: "Ipsum" will be introduced as the new default theme for WordPress 7.2 (Make Core).
  • Collaboration Model: The core team is transitioning to a "server-aware" approach for collaboration (Make Core).
  • Release Format Change: Starting with WordPress 7.2 in early December 2026, the project will move from in-person live releases to a livestreamed webinar format (Make Core).
  • Testing Infrastructure: Gutenberg has officially migrated its JavaScript unit and integration tests from Jest to Vitest to support native ESM and real-browser testing (Make Core).

Developer Implications

  • Security Patching: WordPress 7.1.2 was released to address a critical RCE vulnerability (CVE-2026-87902) involving local PHP file inclusion. Developers must ensure clients are updated, as the fix is backported to versions as old as 4.7 (WordPress.org News).
  • ACF Blocks Migration: Developers moving from ACF Blocks v2 to v3 should focus on implementing inline editing and custom toolbar controls to optimize content workflows (ACF Blog).
  • AI Integration: The new WordPress Trac MCP server allows developers to connect AI clients (like Claude or ChatGPT) directly to Trac to query tickets and changesets (Make Core).
  • Core Contribution Tools: New tools are available to simplify contributing to the ecosystem, including a dedicated toolkit for Gutenberg contributions and a new public repository (WordPress/core-release-utils) containing six CLI tools to automate manual release tasks (Make Core).
