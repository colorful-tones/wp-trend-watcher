Emerging Trends

The primary trend this week is the preparation for the WordPress 7.2 release, scheduled for December 8, 2026. Key developments include:

  • Security and Credential Management: The introduction of the Secrets API (What’s new for developers?, The Secrets API in WordPress 7.2) focuses on encrypting credentials at rest using wp_set_secret() and wp_get_secret().
  • Notification Governance: A new proposal for "declared intent" (WordPress notifications and declared intent) aims to categorize plugin notifications (Operational, Setup, Activity, Feedback, or Promotional) to allow for automated restriction of unauthorized promotional content.
  • AI Integration Architecture: Ongoing work is being done to create a shared "abilities" architecture (AI Contributor Weekly Summary – 4 November 2026) that allows AI assistants to discover and invoke WordPress capabilities via an MCP Adapter.

Developer Implications

  • Secrets API Adoption: Developers should begin planning for the transition to the Secrets API for managing API keys and OAuth secrets. To ensure security, developers must use the plugin-slug/secret-name naming convention and only call reveal() at the specific point of use to avoid plain-text logging (The Secrets API in WordPress 7.2).
  • Styling and UI Updates:
    • WordPress 7.2 will replace Dashicons with inline SVGs in the admin bar and menu (What’s new for developers?).
    • A fix for CSS module class name collisions is being introduced to prevent style overlaps between different versions of the same package (Update bundled @wordpress/* packages).
    • The Options and View menus in the post and site editors are moving to a new @wordpress/ui Menu component, which may affect custom UI layouts (Editor: The Options and View menus now use the new Menu component).
  • Block Development: New native text shadow support is arriving for Paragraph and Heading blocks. Developers can opt-in other blocks by setting textShadow: true in block.json and defining presets in theme.json (New Block Support in WordPress 7.2: Text Shadow).
  • Testing and Release Timeline: The Release Candidate 1 (RC1) is scheduled for November 17, 2026. Developers should monitor the Secrets API testing on multisite installations during this window (AI Contributor Weekly Summary – 11 November 2026).

What I'm Watching

The new Secrets API proposed for part of the upcoming WordPress 7.2 release is getting some critical attention, and could use more hosting testing and developer feedback.

The proposal for declared intent for the WP Feature Notification project looks solid and offers a way for plugins to declare their intent for notifications in core. This allows for usage guildelines and proper tooling to enforce proper usage.

A new "flagship" theme has been announced: Mētis. What the process for including a flagship theme looks like is unclear and how might it add to the overall core bundle size? 🤔

WordPress 7.2 is on the horizon (estimated arrival Dec. 8, 2026) - please give beta-5 a test. 🙏
