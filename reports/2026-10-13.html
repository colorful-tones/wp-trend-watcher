Emerging Trends

The WordPress 7.2 release cycle is currently in the planning and preparation phase. Key milestones include a final release date of December 8, 2026, with a 24-hour code freeze starting December 7 (WordPress 7.2 Release Party Schedule). The release schedule includes weekly Beta parties starting October 20, 2026, followed by RC parties in November (WordPress 7.2 Release Party Schedule).

Significant architectural changes are being integrated into the 7.2 release, specifically:

  • SQL Mode Changes: NO_BACKSLASH_ESCAPES is now turned off by default to ensure backslashes are correctly interpreted as escape characters (NO_BACKSLASH_ESCAPES SQL mode is now turned off by default in WordPress 7.2).
  • Performance Optimizations: Plans are underway to default script and style concatenation to "off" in production and eventually remove load-scripts.php and load-styles.php (Performance Chat Summary: 6 October 2026).
  • Core Refactoring: The wp_kses() function is being replaced with a version based on the HTML API to improve speed and memory usage (Progress Report: wp_kses()).

AI integration is expanding with the release of the MCP Adapter plugin, which allows AI assistants to invoke site functions as tools (The MCP Adapter Plugin is Now Available on WordPress.Org) and the introduction of Markdown feeds for AI agents (What’s new in AI 1.4.0).

Developer Implications

  • Security Updates: Developers should immediately update to WordPress 7.1.3 to mitigate seven security vulnerabilities, including a stored XSS on the Comments administration page and a second-order SQL injection in WXR exports (WordPress 7.1.3 Maintenance and Security Release).
  • Database Compatibility: Because NO_BACKSLASH_ESCAPES is off by default in 7.2, developers who rely on this specific SQL mode must now use the incompatible_sql_modes filter within a db.php drop-in (NO_BACKSLASH_ESCAPES SQL mode is now turned off by default in WordPress 7.2).
  • Frontend & UI Standards: A proposal to standardize Toolbar behavior aims to make the "W" icon consistently link to the Dashboard and the site name consistently link to the front end (Call for feedback: the W and the site name in the Toolbar). Additionally, new CSS Coding Standards will prohibit the order property and *-reverse values to maintain DOM order consistency for accessibility (Proposal: Minor updates to the WordPress Core CSS Coding Standards).
  • API Updates: The Presence API shipped version 0.17.0, adding granular feature toggles and new "arrivals" and "fading-out" scenes (Presence API meeting summary: October 12, 2026).
  • Testing Window: Agencies should prepare for the 7.2 Beta parties starting October 20, 2026, to assist with testing and coordination (WordPress 7.2 Release Party Schedule).

What I'm Watching

The release of the MCP Adapter plugin is a wonderful addition and will hopefully create a bridge for sites to leverage custom Abilities. Also, the latest release of the AI plugin adds an experimentatl feature to allow sites to expose Markdown feeds for AI agents.

Another critical security release dropped on October 6 (WP 7.1.3). Be sure to update your sites! It seems security bounties and reports are escalating amongst the community, This is challenging and beneficial all at the same time.

Finally, the Feature Notifications project is getting some attention and there is active work towards a new and improved replacement for wp_kses(), which looks promising, and would offer a positive performance impact.
