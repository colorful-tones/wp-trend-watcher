### Emerging Trends
The WordPress 7.2 roadmap is a primary focus for the community, with several key changes confirmed:
*   **New Default Theme:** "Ipsum" will be introduced as the new default theme for WordPress 7.2 ([Make Core](https://make.wordpress.org/core/2026/09/16/introducing-ipsum-the-new-default-theme/)).
*   **Collaboration Model:** The core team is transitioning to a "server-aware" approach for collaboration ([Make Core](https://make.wordpress.org/core/2026/09/24/summary-dev-chat-september-23-2026/)).
*   **Release Format Change:** Starting with WordPress 7.2 in early December 2026, the project will move from in-person live releases to a livestreamed webinar format ([Make Core](https://make.wordpress.org/core/2026/09/23/iterating-from-live-events-to-livestreamed-releases/)).
*   **Testing Infrastructure:** Gutenberg has officially migrated its JavaScript unit and integration tests from Jest to Vitest to support native ESM and real-browser testing ([Make Core](https://make.wordpress.org/core/2026/09/23/gutenbergs-javascript-unit-and-integration-tests-now-use-vitest/)).

### Developer Implications
*   **Security Patching:** WordPress 7.1.2 was released to address a critical RCE vulnerability (CVE-2026-87902) involving local PHP file inclusion. Developers must ensure clients are updated, as the fix is backported to versions as old as 4.7 ([WordPress.org News](https://wordpress.org/news/2026/09/wordpress-7-1-2-release/)).
*   **ACF Blocks Migration:** Developers moving from ACF Blocks v2 to v3 should focus on implementing inline editing and custom toolbar controls to optimize content workflows ([ACF Blog](https://www.advancedcustomfields.com/blog/acf-chat-fridays-wordpress-7-1-acf-blocks-v3-and-editor-customization/)).
*   **AI Integration:** The new WordPress Trac MCP server allows developers to connect AI clients (like Claude or ChatGPT) directly to Trac to query tickets and changesets ([Make Core](https://make.wordpress.org/core/2026/09/24/wordpress-trac-mcp-server/)).
*   **Core Contribution Tools:** New tools are available to simplify contributing to the ecosystem, including a dedicated toolkit for Gutenberg contributions and a new public repository (`WordPress/core-release-utils`) containing six CLI tools to automate manual release tasks ([Make Core](https://make.wordpress.org/core/2026/09/23/new-public-repo-core-release-tools/)).
